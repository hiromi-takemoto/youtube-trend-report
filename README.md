# YouTube Trend Report

YouTubeの**実データ**からトレンドを分析し、1枚のHTMLレポートを自動生成するコマンドラインツールです。

「何となく流行っていそう」ではなく、再生数・投稿日・登録者数を実際に取得して数値で判断します。

## できること

| 出力 | 内容 |
|---|---|
| 勢いランキング | 「1日あたり再生数」で並べ替え。昔バズった動画に埋もれず、いま伸びているものが上に来る |
| 狙い目チャンネル | 登録者数のわりに再生が回った動画を抽出。知名度ではなく**ネタの力**で伸びたものが分かる |
| タイトルの型 | 10種類の型を自動判定し、どの型が実際に伸びているかを集計 |
| 頻出キーワード | タイトルから語を抽出して頻度集計 |
| グラフ | 横棒グラフ＋両対数の散布図(外部ライブラリ不使用の自前SVG) |

## サンプル出力

実際に生成したレポート → [docs/sample-report.html](docs/sample-report.html)

キーワード「Claude Code 副業」で実行した結果です。ダウンロードしてブラウザで開くと、そのまま閲覧できます。

## 使い方

```bash
node index.js "AI 副業 初心者"
```

```bash
node index.js "せどり" --days 30 --max 50
```

| オプション | 意味 | 既定値 |
|---|---|---|
| `--days` | 何日前までの動画を対象にするか | 120 |
| `--max` | 取得する動画の件数(1〜50) | 50 |
| `--out` | レポートの保存先フォルダ | `reports` |

生成された HTML をブラウザで開くだけで読めます。オフラインでも開けます。

## セットアップ

必要なのは Node.js 20 以上のみ。**インストールするパッケージはありません。**

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「YouTube Data API v3」を有効化
3. 「認証情報」→「APIキー」を作成
4. プロジェクト直下に `apikey.txt` を作り、キーを1行貼り付ける
   （環境変数 `YOUTUBE_API_KEY` でも可）

## 設計上の判断

### 「1日あたり再生数」を主指標にした理由
単純な再生数だと、数年前にバズった動画が常に上位を占めてしまい、
「いま何が起きているか」が見えません。`再生数 ÷ 投稿からの日数` で正規化しています。

なお、投稿直後の動画を 0.5 日などで割ると
「1日あたり再生数 > 総再生数」という有り得ない値が出て勢いが水増しされるため、
**最低1日**として扱っています。

### 「登録者比」で狙い目を見つける
登録者10万人のチャンネルの10万再生は、ただの地力です。
登録者1,000人のチャンネルの5万再生は、**ネタが当たった**ということ。
後者を見つけるため `再生数 ÷ 登録者数` で並べ替えています。

散布図の点線は `y=x`。この線より上にある動画が「登録者数を超えた」動画です。

### 依存パッケージを持たない
`npm install` が不要なので、環境を選ばず動きます。
グラフも Chart.js 等を使わず SVG を直接組み立てています。

## 制約

- YouTubeの検索は**チャンネル名にもマッチする**ため、キーワードと無関係な動画が混ざることがあります。キーワードは具体的にするほど精度が上がります。
- API無料枠は1日10,000ポイント。1レポートあたり約102ポイントなので、**1日約98回**まで実行できます。
- 登録者数を非公開にしているチャンネルは「狙い目」の集計から除外されます。

## 構成

```

src/api.js        YouTube Data API クライアント
src/analyze.js    型の抽出・狙い目の判定
src/report.js     HTML/SVG レポート生成
```
