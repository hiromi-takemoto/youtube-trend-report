YouTube Trend Report

YouTubeの実データを取得して、「いま何が伸びているか」を1枚のHTMLレポートに自動でまとめるコマンドラインツールです。外部ライブラリを一切使わず、Node.js だけで動きます。

サンプルレポートを見る ソースコードを見る

できること

  • 勢いランキング総再生数ではなく「1日あたり再生数」で並べ替え。昔バズった動画に埋もれず、いま伸びているものが上に来ます。
  • 狙い目チャンネルの発見登録者数のわりに再生が回った動画を抽出。知名度ではなく企画の力で伸びたものが分かります。
  • タイトルの型を分析10種類の型を自動判定し、どの型が実際に数字を取れているかを集計します。
  • グラフを自前生成Chart.js 等は使わず、横棒グラフと両対数散布図を SVG で直接組み立てています。

使い方

node index.js "AI 副業 初心者" と打つだけでレポートが生成されます。npm install は不要です。
